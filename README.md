# 심은하 Web Resume

이 폴더에는 웹 이력서 공개에 필요한 파일만 들어 있습니다. 원본 지원서, 면허증, 작업 문서와 이전 버전은 포함하지 않았습니다.

## 배포 방법

1. GitHub에서 새 저장소를 만듭니다. 저장소 이름은 `eunha-cv`처럼 정하면 됩니다.
2. 이 폴더 자체가 아니라 **이 폴더 안의 모든 파일과 `assets` 폴더**를 저장소 최상위에 업로드합니다.
3. 저장소의 `Settings` → `Pages`로 이동합니다.
4. `Build and deployment`의 Source를 `Deploy from a branch`로 설정합니다.
5. Branch는 `main`, 폴더는 `/ (root)`를 선택하고 저장합니다.
6. 배포가 끝나면 `https://GITHUB-ID.github.io/eunha-cv/`에서 확인합니다.

저장소 이름을 `GITHUB-ID.github.io`로 만들면 주소는 `https://GITHUB-ID.github.io/`가 됩니다.

## 업데이트 방법

웹사이트를 수정한 후 이 배포 폴더의 같은 파일을 교체하고 GitHub에 다시 커밋하면 됩니다. 반영까지 몇 분 정도 걸릴 수 있습니다.

## 공개 정보 확인

배포하면 페이지의 이메일 주소, 전화번호, 프로필 사진, 포스터와 연구 영상이 인터넷에 공개됩니다. 공개 범위를 다시 확인한 뒤 업로드하세요.
